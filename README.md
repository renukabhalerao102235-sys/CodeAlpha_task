# CodeAlpha_task

CodeAlpha Data Analyst Internship

Task 1: Web Scraping

Project Description

This project collects book information from a demo website using Python web scraping.

Tools and Technologies

- Python
- Requests
- BeautifulSoup
- Pandas

Data Collected

The dataset contains the following information:

- Book Title
- Price
- Rating
- Availability

Project Files

- "Scraper.py" – Python script used to scrape book data.
- "Books.data.csv" – CSV file containing the collected book information.

Learning Outcomes

- Understanding web scraping with Python.
- Extracting structured data from web pages.
- Saving collected data into a CSV file.
- Working with datasets using Pandas.
